# Winple Player 1.0.0 — primeira versão

Primeira versão pública do **Winple Player**, um player de áudio
acessível para Windows no estilo Winamp clássico, feito para uso
inteiro pelo teclado e testado com o leitor de tela NVDA.

> Este programa já se chamou *LS AudioPlayer*. Agora se chama **Winple
> Player** — mesmo programa, nome novo e original.

## Como instalar

1. Baixe o arquivo **`WinplePlayer_Setup_V1.0.0.exe`** abaixo, em
   *Assets*.
2. Execute e siga o assistente.
3. Requisitos: Windows 10 ou 11 (64 bits). Nada mais precisa ser
   instalado.

Se o seu antivírus reclamar, é um falso positivo comum nesse tipo de
programa — pode liberar com segurança (mais detalhes no README).

## O que tem nesta versão

- Toca MP3, WAV, OGG, FLAC, M4A, AAC e WMA
- Rádios da internet (Icecast, Shoutcast e HLS), sem cortes
- Rádios e pastas favoritas, com troca estilo radinho (B e Z)
- Cruzamento entre faixas (crossfade), inclusive entre rádios
- Equalizador de 3 bandas, efeitos, normalizador e suporte a VST
- Velocidade e tom ajustáveis
- Listas de reprodução (.m3u, .m3u8, .pls)
- Modo portátil e backup completo das configurações
- Uso 100% por teclado, testado com NVDA (F1 lista todos os atalhos)

O **[manual completo](../blob/main/MANUAL.md)** explica cada recurso.
