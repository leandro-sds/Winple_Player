# Winple Player 1.1.3

Versão de correção, a partir de um relato de usuário.

## O que mudou

- Selecionar muitas músicas no Explorer (por exemplo, com Ctrl+A) e
  apertar Enter agora abre no Winple Player. Antes, com mais de 15
  arquivos, o Windows abria o player padrão dele
- Todas as músicas selecionadas entram numa lista só, em ordem
  alfabética. Antes, mesmo com poucos arquivos, só um deles tocava
- O Windows permite abrir até 100 arquivos de uma vez desse jeito. Para
  mais que isso, abra a pasta: "Reproduzir pasta com Winple Player" no
  menu de contexto, Shift+L ou as pastas favoritas, sem limite
- Depois de instalar, não é mais preciso reiniciar o computador para o
  Windows passar a usar as associações novas

A lista completa está no **[histórico de versões](../blob/main/CHANGELOG.md)**.

## Como instalar / atualizar

Baixe o **`WinplePlayer_Setup_V1.1.3.exe`** abaixo e execute — ele
instala por cima da versão anterior, mantendo suas configurações.

Quem já tem o Winple Player instalado também é avisado automaticamente
desta atualização na próxima vez que abrir o programa.
