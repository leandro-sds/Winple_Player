# Winple Player 1.1.1

Versão de ajustes, com base nos relatos de quem está usando a 1.1.0.

## O que mudou

- Listas vazias agora dizem o que está vazio ("Nenhum podcast
  cadastrado"), em vez de o leitor de tela falar só "indisponível"
- **Ctrl+D** na lista de episódios: o leitor de tela lê a descrição do
  episódio, sem abrir janela
- Plugins VST mais confiáveis: Enter liga e desliga o plugin sem o som
  de erro do Windows, ligar um plugin não recarrega os outros, e quando
  um plugin não ativa o programa diz exatamente por quê
- Atualizar todos os podcasts: quem não pôde ser atualizado aparece com
  o nome e o motivo

A lista completa está no **[histórico de versões](../blob/main/CHANGELOG.md)**.

## Como instalar / atualizar

Baixe o **`WinplePlayer_Setup_V1.1.1.exe`** abaixo e execute — ele
instala por cima da versão anterior, mantendo suas configurações.

Quem já tem o Winple Player instalado também é avisado automaticamente
desta atualização na próxima vez que abrir o programa.
