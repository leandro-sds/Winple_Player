# Winple Player 2.0.4

## Atualização por dentro do programa
- A partir desta versão, o Winple Player se atualiza sozinho, sem abrir o navegador. Quando houver uma versão nova, basta responder "Sim, baixar e instalar": o programa baixa a atualização, falando o andamento, confere se o arquivo chegou inteiro e pergunta se pode fechar para instalar.
- O Windows pede a permissão de costume para instalar. Depois disso, a instalação acontece sem perguntas e o Winple abre de novo sozinho, já atualizado.
- O download pode ser cancelado a qualquer momento. Respondendo "Não" na permissão do Windows, o Winple continua aberto na versão atual.
- Se o download falhar por algum motivo, o programa oferece abrir o navegador, como era antes.
- O Winple portátil também se atualiza por dentro, na mesma pasta onde está, mantendo as configurações e sem a pergunta de permissão do Windows (ela só aparece se a pasta for protegida, como Arquivos de Programas). Como em toda cópia portátil, nada é registrado no Windows: atalhos e menu de contexto continuam sendo só da versão instalada.

Importante: como quem baixa a atualização é a versão que já está instalada, esta atualização para a 2.0.4 ainda acontece pelo navegador. Da próxima em diante, já é tudo por dentro do programa.

## Como instalar / atualizar
Baixe o WinplePlayer_Setup_V2.0.4.exe abaixo e execute. Ele instala por cima da versão anterior, mantendo suas configurações.

Quem já tem o Winple Player instalado também é avisado automaticamente desta atualização na próxima vez que abrir o programa.
